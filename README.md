Для варианта №6 в качестве брокера сообщений используется **RabbitMQ**.

При использовании брокера сообщений необходимо предусмотреть ретраи при подключении к брокеру.

Также необходимо добавить в конфигурацию Aspire запуск генератора и RabbitMQ.

## Предметная область

Музей предоставляет возможность организации экскурсий по выставкам.

В информационной системе хранятся данные об экскурсиях, выставках, посетителях и билетах.

### Экскурсия

Экскурсия содержит:

* дату проведения;
* время начала;
* продолжительность;
* список посещаемых выставок;
* список билетов участников.

### Выставка

Выставка содержит:

* название;
* тему;
* номер зала;
* дату начала проведения;
* дату окончания проведения.

Для хранения темы выставки используется перечисление `ExhibitionTheme`.

В текущей реализации используются следующие темы:

* `History` — история;
* `Art` — искусство;
* `Archaeology` — археология;
* `Science` — наука.

### Посетитель

Посетитель содержит:

* ФИО;
* телефон;
* дату рождения;
* список приобретённых билетов.

### Билет

Билет связан с конкретными:

* экскурсией;
* посетителем.

Также билет содержит:

* тип билета;
* стоимость.

Для типа билета используется перечисление `TicketType`:

* `Adult` — взрослый билет;
* `Discounted` — льготный билет.

### Связь экскурсии и выставки

Поскольку одна экскурсия может посещать несколько выставок, а одна выставка может входить в несколько экскурсий, используется отдельный класс связи `ExcursionExhibition`.
